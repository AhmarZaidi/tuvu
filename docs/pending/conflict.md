We have a feature in settings called merge media. So if we have conflicts for an items (can be within a type ot across types) then we can show that there as well so we can bulk fix it or accept the change one by one or select multiple etc.

The idea for within type conflicts is this: if we have an item with the same name & release date (you can also check for other details to create a matching) it should search the relevant API for that media and see which is the best match and suggest to keep that one.

For across type we can match by id, name & release date etc as relevant - should only be true where multiple data is coming from same id
